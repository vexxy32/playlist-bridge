# Тесты

- `server/` — HTTP-обработчики, авторизация, экспорт и перенос плейлистов.
- `spotify/` — клиент Spotify.
- `transfer/` — сопоставление треков, перенос и адаптеры.
- `youtube/` — клиент YouTube.

Из корня проекта:

```sh
go test -tags playlist_bridge_tests -overlay tests/overlay.json ./internal/...
```

Overlay подключает файлы к их исходным Go-пакетам, чтобы тесты могли обращаться к закрытым функциям и состоянию. Тег включает файлы для этого запуска. Ответы провайдеров в тестах подставляются локальными моками.
